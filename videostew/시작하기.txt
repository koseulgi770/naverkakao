============================================================
  비디오스튜 자동화 - 빠른 시작 안내
============================================================

이 폴더는 "구글시트에 URL을 넣으면 → 비디오스튜가 영상 제작 →
유튜브 업로드"까지 자동으로 해주는 프로그램입니다.


■ 실행 방법 (윈도우)
------------------------------------------------------------
1) 이 압축을 폴더에 풉니다.
2) run.bat 파일을 더블클릭합니다.
3) 처음 실행하면 config.json 을 만들고 메모장으로 열어줍니다.
   → 아래 값들을 채우고 저장한 뒤, run.bat 을 다시 더블클릭하세요.


■ 실행 방법 (맥 / 리눅스)
------------------------------------------------------------
터미널에서:  bash run.sh


■ config.json 에 채워야 할 값
------------------------------------------------------------
- apiKey / apiToken
    비디오스튜 https://videostew.com/ko/dev/apps 에서 발급

- google.spreadsheet_url
    영상으로 만들 URL을 적을 구글시트 주소
    (첫 행 헤더:  url | status | videoUrl | completedAt)

- service_account.json
    구글 서비스 계정 키 파일. 이 폴더에 같이 넣어주세요.
    ※ 해당 시트를 서비스 계정 이메일과 '편집자'로 공유해야 합니다.

- youtube.client_secret.json
    유튜브 업로드용 OAuth 키. 이 폴더에 같이 넣어주세요.
    (유튜브 업로드가 필요 없으면 config.json 의
     "youtube": { "enabled": false } 로 바꾸세요.)


■ 중요 (최초 실행 시)
------------------------------------------------------------
비디오스튜 API 응답 형식을 화면에 자세히 출력합니다(--debug).
혹시 "projectId를 찾지 못했습니다" 같은 오류가 나오면,
README.md 의 "API 응답 필드명 확인 필요" 항목을 참고하거나
그 화면을 캡처해서 문의해 주세요. 바로 맞춰드립니다.


자세한 설명은 README.md 파일을 참고하세요.
