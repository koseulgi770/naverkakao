# naverkakao

윈도우용 자동화 도구 모음입니다.

## 1. 네이버 스마트스토어 → 카카오톡 주문 알리미 (`main.py`)

네이버 커머스 API로 신규 주문을 감지해서 PC 카카오톡 오픈채팅방에 자동으로 알림을 보냅니다.

```
pip install -r requirements.txt
python main.py
```

`config.json`에 네이버 커머스 Client ID / Secret, 오픈채팅방 이름을 입력한 뒤 실행합니다.

## 2. Lilys AI → 네이버 블로그 자동 포스팅 (`lilys_to_blog.py`)

두 가지 방식으로 글을 가져와 네이버 블로그에 자동 발행합니다.

- **유튜브 링크 방식**: 유튜브 링크를 입력하면 Lilys AI 공식 API로 요약(블로그 글 형식)을 생성해 발행합니다.
  - [Lilys AI API 키](https://lilys.ai/api/) 발급이 필요하며, 크레딧이 차감됩니다.
- **보관함 감시 방식**: 로그인된 브라우저로 [Lilys 보관함](https://lilys.ai/collections)을 주기적으로 확인해서,
  새로 추가된 노트를 자동으로 블로그에 발행합니다. (첫 실행 시 기존 노트는 건너뛰고, 이후 새 노트만 발행)

### 사용 방법

```
pip install -r requirements.txt
python lilys_to_blog.py
```

1. 크롬(Chrome)이 설치되어 있어야 합니다.
2. **[🔑 로그인용 브라우저 열기]** 버튼을 눌러 열리는 브라우저에서 **네이버**와 **Lilys AI**에 로그인합니다.
   (전용 크롬 프로필에 세션이 저장되어 이후에는 자동으로 유지됩니다)
3. 유튜브 링크를 넣고 **[▶ 요약 → 블로그 발행]** 을 누르거나, **[👀 보관함 감시 시작]** 을 켜 둡니다.
4. `발행 방식`을 `draft`로 바꾸면 바로 발행하지 않고 임시저장만 합니다. 처음에는 `draft`로 테스트해 보는 것을 권장합니다.

### 참고 / 주의

- 네이버 블로그는 공식 글쓰기 API가 2020년에 종료되어, 브라우저 자동화(Selenium)로 발행합니다.
  네이버 에디터 화면 구조가 바뀌면 발행이 실패할 수 있으며, 로그에 원인이 표시됩니다.
- 자동 발행 글이 과도하면 네이버 정책(스팸/저품질)에 걸릴 수 있으니 발행 주기와 글 품질에 유의하세요.
- 요약 글을 게시할 때는 원본 영상 출처가 본문 하단에 자동으로 포함됩니다.
